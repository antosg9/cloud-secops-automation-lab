## 🎉 Welcome

Welome to the **cloud-secops-automation-lab**, a lab designed to learn the basis of secured cloud automation.

## 📋 About

EN - IaC deployment (Terraform) of a secure AWS architecture: creation of a segmented network (VPC, subnets) with restricted access via Bastion (Zero-Trust).

FR - Déploiement IaC (Terraform) d'une architecture AWS sécurisée : création d'un réseau compartimenté (VPC, Subnets) avec accès restreint via Bastion (Zero-Trust)
